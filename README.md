# Bitogram Web Client

Web client for Bitogram — a fast and simple messenger with a custom binary protocol.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite 7**
- **PWA** (`vite-plugin-pwa`) — installable as a native-like app, offline support
- **Argon2** (`@sphereon/isomorphic-argon2`) — password hashing
